# Учёт рейсов — «Путевой»

## Запуск
Откройте «Учёт-рейсов.html» в современном браузере. Это автономный файл: стили и JavaScript включены внутрь. Интернет, сервер, сборка и регистрация не нужны.

Также можно открыть index.html рядом с app.js, core.js и style.css.
Если браузер ограничивает localStorage для локальных файлов, запустите из папки исходников `python3 -m http.server 8000` и откройте http://localhost:8000. Всегда используйте один адрес и браузер: хранилища для file:// и http://localhost раздельны.

## Работа
Выберите месяц, год, число и магазин. Маршрут подставится из справочника. При добавлении второго магазина создаются две независимые записи: первая на выбранный день, вторая на следующий календарный день. Запись за следующий месяц появится в его журнале. Редактирование и удаление каждой записи выполняется отдельно.

Совпадение даты и магазина считается дубликатом. При конфликте любого из двух рейсов обе новые записи отклоняются.

Справочник позволяет добавлять, редактировать и удалять магазины. Магазин, используемый в рейсах, можно редактировать; удаление заблокировано до удаления связанных рейсов. Маршруты и названия в истории рейсов сохраняются как снимок. Изменение справочника влияет только на новые рейсы. Демонстрационные магазины явно отмечены, реальных маршрутов в поставке нет. Журнал изначально пуст.

Экспортируется выбранный месяц: CSV с разделителем «;», UTF-8 BOM, экранированием кавычек и защитой текстовых ячеек от формул. В Excel при необходимости выберите разделитель «точка с запятой».

## Данные
Ключ localStorage: putevoi-trips-v1. Данные остаются после перезагрузки и закрытия браузера. Не используйте приватный режим для постоянного журнала. Очистка данных сайта удаляет журнал. Данные между устройствами и браузерами не синхронизируются. При конфликте вкладок приложение просит перезагрузить данные и не перезаписывает их. Ошибки чтения/записи хранилища отображаются пользователю.

## Проверено
Автоматические тесты Chromium: обычный рейс; два магазина на соседние дни; 31 января → 1 февраля; редактирование; перезагрузка; фактическое скачивание CSV с проверкой содержимого и фильтра месяца. Дополнительно: дубликаты, 31 декабря → 1 января, создание и редактирование магазина с сохранением, отмена и подтверждение удаления, экран 390px без горизонтального переполнения, отсутствие ошибок JavaScript. Этот набор выполнен и для отдельных исходников, и для автономного HTML.

Отдельная проверка с постоянным профилем Chromium подтвердила сохранение после полного закрытия и повторного запуска браузера.

6 тестов Node.js проверяют логику, атомарность пары при дубликате, високосный год, конфликт редактирования, CSV и некорректные входные данные.

Исправленная ошибка: при переключении с 31 января на февраль предпросмотр обновлялся до корректировки числа. Теперь число ограничивается последним днём месяца до обновления формы.

Ограничения среды проверки: прямое открытие file:// заблокировано политикой управляемого Chromium; браузерные сценарии выполнялись через перехват HTTP-запросов, возвращающий неизменённые локальные файлы. Установка приложения не требуется. Сервис Sites preview недоступен, публичная публикация не выполнялась.
